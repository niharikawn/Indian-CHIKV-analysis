# Genome Analysis

This directory contains scripts and documentation for the analysis of Indian Chikungunya virus (CHIKV) complete-genome sequences.

## Workflow

The genome analysis workflow includes:

- Data recovery and organization
- Metadata and sequence curation
- Genome-level sequence processing
- Multiple sequence alignment
- Phylogenetic analysis
- Temporal analysis
- Bayesian evolutionary analysis

Sequence data and unpublished analysis results are not included in this repository.
