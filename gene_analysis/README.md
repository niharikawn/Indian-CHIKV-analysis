# Gene-Level Analysis

This directory contains the workflow used for gene-level analysis of Indian Chikungunya virus (CHIKV) sequences.

The gene-level analysis is performed separately from the complete-genome analysis.

## Dataset

The gene-level workflow uses Indian CHIKV gene sequences for downstream evolutionary and selection-pressure analyses.

## Workflow

Data Recovery
      ↓
Data Curation
     ↓
Sequence Quality Control
     ↓
Gene Extraction / Preparation
     ↓
Multiple Sequence Alignment
     ↓
Sequence Filtering
     ↓
Selection Pressure Analysis
    ↓
Interpretation of Results

## Data Privacy

Raw sequences, private/in-house sequences, accession lists, curated metadata, and unpublished study-specific results are not included in this public repository.
