# Indian CHIKV Analysis

Bioinformatics analysis of Indian Chikungunya virus (CHIKV) isolates using Google Colab.

## Project Overview

This project focuses on the curation and analysis of Indian CHIKV isolates.

The workflow includes:

- Data retrieval
- Metadata curation
- Sequence quality control
- Sequence filtering
- Multiple sequence alignment
- Phylogenetic analysis
- Mutation analysis
- Selection pressure analysis

## Study Focus

The analysis focuses on Indian CHIKV isolates and their genetic variation, evolutionary relationships, and molecular characteristics.
